# Adding Extra Time for a Candidate

Recruiters can grant extra time to a candidate for accessibility or
accommodation reasons before they start a test.

## Steps
1. Open the **Tests** tab and select the relevant test.
2. Go to the **Candidates** tab and select the candidate.
3. Click **More** > **Add Time Accommodation**.
4. Enter the accommodation percentage (e.g. 25%, 50%).
5. Click **Save**.

The extra time is applied automatically the next time the candidate
starts the test. It cannot be added retroactively once a test is in
progress.

## Notes
- Only test administrators and recruiters with edit access can grant
  accommodations.
- Extra time changes are logged in the candidate's activity history
  for audit purposes.
