# Reviewing Plagiarism Flags on Submissions

Submissions flagged for similarity above the configured threshold are
marked for manual review and are not auto-rejected.

## How flags are generated
- Code similarity is compared against other candidates in the same
  test and against a reference database of common solutions.
- A similarity score above the test's configured threshold (default
  70%) triggers a flag.

## Reviewing a flag
1. Open the candidate's submission report.
2. Click the **Plagiarism** tab to see the matched submission(s) and
   a side-by-side diff.
3. Mark the flag as **Confirmed**, **Not Plagiarism**, or **Needs
   Discussion**.

Candidates are never notified directly that their submission was
flagged; recruiters decide next steps.
